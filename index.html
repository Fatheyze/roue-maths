☁ Synchronisation GitHub privée

Utilisez un jeton personnel autorisé à lire et écrire dans votre dépôt privé. Le jeton reste dans le stockage local de ce navigateur, jamais dans le HTML ni dans le fichier JSON synchronisé. Sur un ordinateur partagé, protégez votre session.

Au premier accès, le fichier roue-maths-v3.json est créé automatiquement dans votre dépôt privé. Les ouvertures suivantes récupèrent les dernières notes. En cas de conflit, aucune sauvegarde n’est écrasée automatiquement.
